# 日历月视图

## Goal

在现有日历视图中增加“月视图”，让用户可以按自然月快速扫视课程、考试和待办截止分布，并能从月历日期进入已有日视图查看当天详情。

## Requirements

- 日历页视图切换从当前 `周视图 / 日视图` 扩展为 `月视图 / 周视图 / 日视图`，保持现有日视图和周视图行为不回退。
- 月视图按自然月展示，周从周一开始，补齐月初/月末所在周，使桌面和移动端都能稳定展示 5-6 行日期格。
- 月视图必须使用现有日历事件契约展示课程、考试和待办，不在前端自行合并独立数据源。
- 月视图中的日期格至少展示：
  - 日期数字
  - 今天高亮
  - 非当前月日期的弱化状态
  - 当天事件数量或紧凑事件摘要
  - 课程、考试、待办三类来源的可区分视觉标识
- 点击月视图日期后，选中该日期并切换到日视图，日视图展示该日期的完整事件列表。
- 顶部上一页/下一页导航在月视图中切换自然月，在周/日视图中继续切换周。
- 顶部日期标题在月视图中展示目标自然月，例如 `2026年7月`；“今天”按钮在月视图中回到当前月份并选中今天。
- 加载、错误、空状态必须覆盖月视图；空月份不能误显示为页面无数据错误。
- 移动端触摸目标不小于 44dp，月历单元不因事件标题长度导致横向溢出。

## Acceptance Criteria

- [ ] 用户可以在日历页切换到 `月视图`，再切回 `周视图` / `日视图`，状态和布局正常。
- [ ] 月视图展示自然月完整网格，包含跨月补齐日期，周一到周日顺序正确。
- [ ] 月视图中的课程、考试、待办来源与现有 `CalendarEvent.kind` 一致，点击事件或日期不会跳转到错误模块。
- [ ] 点击任一日期后进入日视图，并展示该日期的事件；无事件日期展示当天空状态。
- [ ] 上一页/下一页在月视图按月切换，在周/日视图按周切换。
- [ ] `今天` 行为在月视图和周/日视图中都符合当前日期语义。
- [ ] `npm run lint` 和 `npx tsc --noEmit` 通过。
- [ ] 宽度小于 768px 时，月视图没有文字重叠、横向溢出或不可点击的小按钮。

## Definition of Done

- 前端代码遵循 `.trellis/spec/frontend/index.md`、`component-guidelines.md`、`quality-guidelines.md`、`type-safety.md`。
- 不引入外部网络请求，不新增全局状态库，不复制后端 IPC 类型。
- 如实现过程中发现需要后端聚合接口，必须先回到 planning 更新本 PRD 和 `design.md`。
- 完成后评估是否需要更新 `.trellis/spec/`，再进入提交计划。

## Out of Scope

- 不实现拖拽创建/调整日程。
- 不实现月视图内直接编辑课程、考试或待办。
- 不新增独立“年视图”或范围搜索。
- MVP 不新增后端 `get_calendar_month` command；除非实现验证证明现有周接口无法满足性能或正确性要求。
